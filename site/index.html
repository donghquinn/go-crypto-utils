Seven tools, one window

Each tab does one job and does it without ceremony.

Encryption

AES-CBC and AES-GCM with 128, 192 or 256-bit keys. Generate a key inline if you don't have one yet.

Decryption

Decrypt Base64 ciphertext with the matching key. Errors surface in the UI instead of silently yielding an empty box.

Encoding

Text to Base64 or Hexadecimal, as much of it as you care to paste.

Decoding

Base64 or Hex back to text, with the same tolerance for input shape.

Key generation

Random AES-128, AES-192 or AES-256 keys, shown in both Hex and Base64 so they drop straight into whatever needs them.

UUIDs

RFC 4122 version 4, one click at a time.

Random strings

1 to 128 characters of [a-zA-Z0-9], length set by a slider.

Keys in either encoding

Paste a key as Hex or Base64. The input is tried as Hex first and falls back to Base64 — no format toggle to get wrong.

Why it's safe to paste a key into

It cannot phone home

The app makes no network requests. Navigation and new windows are blocked outright, and the renderer runs under a restrictive Content-Security-Policy.

The renderer never holds secrets

contextIsolation and sandbox are on, nodeIntegration is off, and the preload exposes a fixed list of IPC channels — nothing more.

Real crypto primitives

All cryptography runs in the main process on Node's node:crypto: AES-CBC and AES-GCM, PKCS#7 padding, randomBytes for keys and strings.

Compatible with the Go build

Ciphertext from the original Go/Fyne version decrypts here and vice versa, verified across AES-128/192/256 with both Hex and Base64 keys.

Two quirks are preserved on purpose so old ciphertext still opens: AES-CBC output is Base64-encoded twice, and AES-GCM output is Base64-encoded once over nonce || ciphertext || tag.

        First launch shows a warning — here's why

        Builds are unsigned, so both desktop platforms will ask before running an app they haven't seen before.

        macOS. Right-click the app and choose Open, or clear the quarantine flag: 

        xattr -dr com.apple.quarantine "/Applications/Secure Helper.app"

        Windows. SmartScreen shows a prompt — choose More info, then Run anyway.

        Linux. The AppImage needs its executable bit set before it will run: 

        chmod +x "Secure Helper-__VERSION__-x86_64.AppImage"

        Prefer to build it yourself? npm ci && npm run dist produces every installer above from a single host.
